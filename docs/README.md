# Documentation

This directory will contain:
- `SRS.md` — Software Requirements Specification
- `ER-diagram.*` — Entity-relationship diagram
- `use-cases.md` — Use case descriptions
- `sequence/` — Sequence diagrams (report flow, status transitions, Python fallback)
- `api/` — OpenAPI spec (also auto-generated by Springdoc)
- `test-reports/` — Test execution results
- `pilot-results/` — Metrics from the pilot
- `runbook.md` — Deployment and operations runbook
- `privacy-data-retention.md` — Privacy and data retention policy

Populate these iteratively as each phase is built.
